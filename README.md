# Weather Stat Atlas

Interactive weather dashboard with a clickable atlas, country selector, and live climate stats. Data is powered by the Open-Meteo API.

## Features

- Clickable country hotspots on an abstract world map
- Dropdown selection as a fallback
- Current temperature, humidity, wind, and precipitation probability
- 5-day max/min temperature trend

## Getting Started

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.

## Data Source

Weather data comes from https://api.open-meteo.com and requires no API key.
